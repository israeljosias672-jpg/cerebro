# GitHub como fuente de verdad

- Fecha: 2026-11-16
- Estado: vigente
- Relacionado con: [segundo cerebro](../proyectos/segundo-cerebro.md)

## Decisión
Las notas viven en este repo privado de GitHub. Graphify se usa para buscarlas y relacionarlas.

## Por qué
- GitHub da respaldo e historial de cambios.
- En el plan gratuito, Graphify en la nube indexa poco de un repo de notas.
