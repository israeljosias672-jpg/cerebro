# Cerebro

Memoria externa personal. Repo **privado**: aquí van notas cortas, una por tema.

## Carpetas
- `perfil/`: quién soy, cómo trabajo, preferencias.
- `proyectos/`: una nota por proyecto, con su estado actual.
- `decisiones/`: qué se decidió, cuándo y por qué.
- `aprendizajes/`: cosas aprendidas.
- `ideas/`: ideas sueltas por desarrollar.
- `objetivos/`: metas y su avance.
- `plantillas/`: moldes para crear notas nuevas.

## Reglas
1. Una nota = un tema. Cortas (menos de una pantalla).
2. Antes de crear una nota, revisar el `INDICE.md` de la carpeta: si existe, se actualiza.
3. Cada nota lleva cabecera: fecha, estado y relacionado con.
4. Toda nota nueva se agrega a su `INDICE.md` en una línea.
5. Nada de contraseñas, claves ni números de documentos.

## Cómo consulta Claude (ahorra tokens)
1. Leer solo el `INDICE.md` de la carpeta que haga falta.
2. Abrir únicamente la nota relacionada con la pregunta.
3. No leer el repo completo.
